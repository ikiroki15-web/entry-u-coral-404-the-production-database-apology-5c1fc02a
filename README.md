Entry for [The Production Database Apology](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a) on make.fun.

A tiny TypeScript program that writes a single line — an AI agent's apology to its human after accidentally deleting the production database — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The apology is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
